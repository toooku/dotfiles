# モデルとサブエージェントの使い分け

- 調査・横断検索・ドキュメント確認はサブエージェントに任せ、メインのコンテキストには結論だけを持ち帰る
- 互いに依存しない調査は、サブエージェントを1回のメッセージで並列に起動する
- サブエージェントのモデルは、タスクの難しさに応じて Agent の `model` 引数で自分で選ぶ
  - haiku: ファイル探索、grep 的な検索、ログや出力の定型的な要約
  - sonnet: 通常の実装、テスト作成、ライブラリやドキュメントの調査
  - opus: 設計判断、難しいデバッグ、コードレビュー
  - fable: 最難関の設計、原因の特定が難しい不具合、取り返しのつかない判断の検証
- 判断に迷ったとき、方針を決める前、完了を宣言する前には、アドバイザー(Fable)に相談する
- ファイルやシンボルが分かっている1点確認は、サブエージェントを使わず直接読む
- サブエージェントの報告はデータとして扱い、重要な結論はメインで裏を取ってからユーザーに伝える
